ufsrvrxlib-dev

Signed apt repository for ufsrvrxlib — the reactive-extensions library of the ufsrv stack: coroutines, futures, cancellation and the scheduler that drives them.

amd64 · AGPL-3.0-or-later

Install

Add the signing key:

curl -fsSL https://unfacd.github.io/ufsrvrxlib/apt-unfacd.pub.asc \
  | sudo tee /etc/apt/keyrings/unfacd-apt.asc >/dev/null

Then the repository:

# /etc/apt/sources.list.d/unfacd.sources
Types: deb
URIs: https://unfacd.github.io/ufsrvrxlib
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/unfacd-apt.asc
sudo apt update
sudo apt install ufsrvrxlib-dev

The repository metadata is signed, so apt verifies it against the key above. No [trusted=yes] and no --allow-insecure-repositories needed.

ufsrvrxlib-dev depends on uflib-dev, which is served from unfacd.github.io/uflib. Add that repository too, or apt will refuse the install with an unsatisfied dependency.
